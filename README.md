# EdBytes Milestone 5 – Four-operation calculator

## Run the project
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Enter two numbers and click Add, Subtract, Multiply or Divide.

No installation or server is required.

## Files
- `index.html` – calculator structure and input fields
- `style.css` – responsive styling
- `app.js` – four operations and input validation
- `TEST-EXAMPLES.md` – five test examples and submission notes

See `TEST-EXAMPLES.md` for the five required tests.
